## 一、关于“价格 & 市场”的底层认知

*   **底部是区间，不是点**

    *   不追求抄到最低，只要：

        *   价格合理 + 风险可控 + 逻辑清晰
            → 就是可以出手的区间。

*   **顶部更像点，但也别指望卖在最高**

    *   涨到「明显离谱、预期透支、情绪极端乐观」的时候，
        → 减仓 / 出清，不恋战。

*   **短期利润暴涨，多半是价格驱动**

    *   周期股 / 低壁垒行业：

        *   利润暴涨 = 大多来自价格上行，而不是公司能力提升。

        *   **利润暴涨往往是出货机会，不是买入信号。**

*   **“别人恐惧时买入”不是圣经**

    *   问题是：**为何恐惧？**

        *   如果是基本面崩了（资不抵债、需求坍塌）
            → “恐惧时买入” = 接刀子。

        *   如果是情绪杀估值，但基本面稳定
            → 才是机会。

## 二、公司本质：股票背后永远是公司

*   **股票 = 公司未来现金流的份额**

    *   股价每天变，**公司行为不一定每天变**。

    *   股价跌：

        *   若营收、护城河、商业模式都还在 → 很可能是机会；

        *   若盈利模式、核心地位被动摇 → 可能是价值塌陷的开始。

*   **商业模式是根，利润只是果**

    *   要优先看得懂的公司：

        *   行业地位清晰（苹果、茅台、谷歌这类）。

        *   收益结构简单，赚钱方式「大家都看得见」。

    *   少去考验自己“算得比市场还准”的能力 ——
        **估值精算对普通人是高难度，连老板都算不准。**

*   **核心入口型业务 = 公司的“命根子”**

    *   谷歌：搜索入口

    *   腾讯：微信入口

    *   这类入口：

        *   本身未必最赚钱；

        *   但一旦被替代，整个公司估值体系会剧变。

    *   一旦核心入口被新技术威胁（如 OpenAI 对搜索的威胁）：

        *   对稳健投资者来说 → **大风险信号，可以先退后看清再说。**

## 三、估值 & 盈利：公司的唯一投资人是它自己

*   **市场能把 100 亿炒到 1000 亿，不代表就值 1000 亿**

    *   真正能支撑市值的，是：

        *   **现在的盈利水平 + 未来持续增长的能力。**

*   **高 PE 不一定错，关键看未来盈利**

    *   如果：

        *   现在赚 10 亿，给 30 倍 PE = 300 亿；

        *   3–5 年后有机会赚 50 亿 → 实际未来 PE 会被盈利增长“消化”。

    *   你是在买：

        *   **未来盈利曲线**，不是当前静态数字。

*   **公司的价值，最终只能靠公司自己“赚”出来**

    *   不是靠：

        *   概念

        *   故事

        *   客户数

        *   短期运营动作

    *   而是：

        *   长期 **净利润持续增长**

        *   护城河没有被侵蚀。

## 四、周期股 / 热点股：特别的警戒规则

*   **周期股（赣锋锂业这类）**

    *   利润 = 价格 × 周期

    *   价格涨 → 利润暴增 → PE 看起来很低 → 极容易误导。

    *   但：

        *   高利润 → 刺激大量新产能 → 价格掉头 → 利润塌陷 → PE 飙升。

    *   核心结论：

        > 周期股利润暴涨，多数是出货窗口，不是价值拐点。

*   **光模块等“单点技术 + 产能短缺”热点**

    *   短期：

        *   订单爆发

        *   利润暴增

        *   估值情绪拉满

    *   问题：

        *   技术门槛不够高；

        *   没有体系化护城河；

        *   高利润必然吸引竞争 + 替代方案。

    *   对散户：

        > 这类标的适合专业交易者，不适合“长期拿着就好”的逻辑。\
        > 你倾向的是价值+长期，那这类应该主动避开。

## 五、创始人、价值观 & 纠错能力

*   **短期困难 = 考验的是：利润未来性 + 创始人处理问题的能力**

    *   例如小米事件：

        *   你是否依然相信：**长期利润会持续增长？**

        *   你是否相信：**雷军有能力、有意愿把事处理好？**

            *   看过往记录：

                *   是有始有终，还是半途而废？

                *   遇到危机是甩锅、遮掩，还是正面解决？

    *   两个问题都“是”：
        → 大跌可能就是黄金坑。

    *   任何一个是“否”：
        → 可能是价值故事开始破碎。

*   **公司犯错时，要区分两种错误：**

    *   **可纠错的业务/产品错误：**

        *   产品方向看走眼；

        *   某个型号失败；

        *   战略犯错但愿意改。
            → 只要价值观是「为用户创造价值」，且有纠错机制，
            **大跌反而是买点。**

    *   **价值观层面的错误：**

        *   为了短期利润，主动伤害用户体验；

        *   靠欺骗/灰色手段赚钱；
            → 这类公司就算利润好看，也要远离。

## 六、商业模式偏好：你“喜欢”和“讨厌”的东西（可以写进铁律）

*   **你讨厌的：**

    *   银行：

        *   利润前置、风险后置；

        *   真正的风险在资产端，几年后才集中爆发；

        *   低 PE 是对模式的定价，不是白捡便宜。
            → **你的系统里：银行 = 长期回避区。**

    *   周期矿、短期暴利 + 无护城河的热门制造：

        *   利润高度依赖价格 / 政策；

        *   长期不确定性大；
            → 只能当「周期交易品种」，不适合你的“长期逻辑投资”。

*   **你偏爱的：**

    *   茅台这类：

        *   成本极低 + 品牌极强 + 可以下沉市场 + 产品不易过期甚至升值；
            → 商业模式极优秀，属于“好公司里最好的那档”。

    *   苹果这类：

        *   溢价能力强；

        *   行业地位稳；

        *   用户愿意为品牌/生态买单。

    *   核心模式：

        > 低成本 + 强品牌 + 可持续提价 / 下沉能力 + 护城河稳固

## 七、你的“投资操作系统”四步法

你说得很对：
**“写在纸上没用，要刻进内核。”**
那就整理成一个你每次都可以 mentally 扫一遍的流程：

### 第一步：记忆（规则内化）

反复抄 & 反复说，就是在做一件事：

> 把这些规则变成 本能反应，不是临时查笔记。

你现在已经很接近了。

***

### 第二步：理解（模型化）

每条规则都要对应一两个**案例**：

*   周期暴利 → 赣锋 / 光模块

*   核心入口 → 谷歌搜索 / 微信

*   价值观错误 → 那些为了利润坑用户的公司

*   好商业模式 → 茅台 / 苹果

**规则 + 具体公司绑定**，记忆会牢很多。

***

### 第三步：行动前 Checklist（关键）

以后每次想重仓 / 加仓 / 换股，你可以问自己这一串问题（可以打印出来贴桌上）：

*   **这家公司赚钱模式，我真看懂了吗？（一句话就能说清？）**

*   **它现在遇到的是：周期问题 / 业务问题 / 价值观问题？**

*   **当前利润是：正常水平 / 周期暴利 / 短期受压？**

*   **现在的价格，是在：底部区间 / 中部 / 明显泡沫？**

*   **创始人/管理层：过往危机处理记录如何？值得我信任吗？**

*   **这家公司，更像：苹果/茅台，还是光模块/周期矿？**

*   \*如果今天股价再跌 30%，我会：

    *   想加仓？

    *   想止损？

    *   还是睡不着？\*\*

> 能回答得很稳，才动手。

***

### 第四步：迭代（不断修正规则）

*   做错一次，就问：

    *   **是规则错了，还是我执行没按规则来？**

*   发现某条规则过于绝对，就微调：

这就是你说的：

> “不停增加规则 → 再筛选 → 最终沉淀出真正对的那几条。”
